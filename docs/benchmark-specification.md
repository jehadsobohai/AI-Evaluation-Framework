# Benchmark Specification

## Purpose

A benchmark is a reproducible evaluation case used to assess one or more AI systems using the AI Evaluation Framework.

Each benchmark must contain sufficient information for another evaluator to reproduce the evaluation.

---

## Required Sections

### 1. Benchmark Information

- Benchmark ID
- Title
- Version
- Date
- Status

---

### 2. Objective

Describe what is being evaluated.

---

### 3. Domain(s)

- Primary Domain
- Secondary Domain(s), if applicable

---

### 4. Prompt

The exact prompt presented to every model.

---

### 5. Models Evaluated

List every evaluated model and version.

---

### 6. Responses

Include the complete responses exactly as generated.

---

### 7. Evaluation Methodology

Specify:

- Methodology used
- Rubrics applied
- Scoring Guide
- Decision Rules

---

### 8. Evaluation Report

Include the complete evaluation report.

---

### 9. Preferred Response

State the preferred response and justify the decision.

---

### 10. Confidence Rating

Low / Medium / High

---

### 11. Limitations

Describe factors affecting interpretation.

---

### 12. Lessons Learned

Summarize key observations.
