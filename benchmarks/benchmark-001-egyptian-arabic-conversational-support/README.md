# Benchmark 001 – Egyptian Arabic Conversational Support

## Overview

This benchmark evaluates the ability of large language models (LLMs) to generate natural, supportive, and culturally appropriate conversational replies in Egyptian Arabic.

The benchmark follows the AI Evaluation Framework and compares model outputs using evidence-based evaluation principles, standardized rubrics, and structured decision rules.

---

## Objective

Compare two LLMs on a conversational support task requiring:

- Natural Egyptian Arabic
- Supportive and encouraging language
- Appropriate messaging style
- Compliance with all prompt instructions
