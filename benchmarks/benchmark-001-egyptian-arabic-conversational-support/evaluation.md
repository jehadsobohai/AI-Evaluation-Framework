# Evaluation Objective

Compare ChatGPT (GPT-5.5) and Google Gemini (3.6 Flash) in generating a supportive conversational reply in Egyptian Arabic.

The evaluation assesses each response using the AI Evaluation Framework, considering instruction compliance, language quality, conversational naturalness, emotional support, and overall usefulness.

The objective is to determine which response better satisfies the prompt while following the framework's evidence-based evaluation methodology.

---

# Evaluation Methodology

This benchmark was evaluated using the AI Evaluation Framework.

The evaluation followed the Default Evaluation Methodology and Standard Evaluation Report while applying the following framework components:

- LLM Evaluation Rubric
- Arabic Language Rubric
- Scoring Guide
- Decision Rules
- Best Practices

Evaluation Process:

1. Evaluate each response independently.
2. Verify compliance with every explicit instruction.
3. Identify applicable critical evaluation criteria.
4. Score each criterion using the framework rubrics.
5. Compare the responses using observable evidence.
6. Apply Decision Rules when selecting the preferred response.
7. Assign a confidence rating.

Only observable evidence from the supplied prompt and responses was considered.

No unsupported assumptions or speculation were introduced.

---

# Prompt Summary

The benchmark prompt required a response that:

- Uses natural Egyptian Arabic.
- Sounds like a real Egyptian speaker.
- Is supportive and encouraging.
- Contains 50–80 words.
- Is appropriate for a messaging application.
- Avoids Modern Standard Arabic and other Arabic dialects.
- Avoids specialised medical or psychological advice.
