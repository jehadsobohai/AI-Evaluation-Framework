# COMET Translation Evaluation Example

## Overview

This example demonstrates how to evaluate English–Arabic translations generated by Large Language Models (LLMs) using the COMET neural evaluation metric within the **AI Evaluation Framework**.

The example illustrates a complete evaluation workflow, from preparing evaluation assets to interpreting COMET scores in a transparent and reproducible manner.

---

## Learning Objectives

This example demonstrates how to:

- Organize benchmark assets
- Prepare COMET input files
- Execute COMET evaluations
- Compare model outputs
- Document evaluation results
- Support reproducible evaluation workflows
