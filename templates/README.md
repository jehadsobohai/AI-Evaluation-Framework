# Templates

This directory contains reusable templates that support the development of standardized AI evaluation projects.

Templates help ensure consistency in project documentation, reporting, benchmark development, and evaluation workflows.

Available templates may include:

- Evaluation Report Template
- Benchmark Template
- Evaluation Project Template
- Metadata Template
- Scoring Template

Templates should be adapted as needed while preserving the principles of transparency, reproducibility, and evidence-based evaluation defined by the AI Evaluation Framework.
