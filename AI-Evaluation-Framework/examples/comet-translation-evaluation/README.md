# COMET Translation Evaluation Example

## Overview

This example demonstrates how to evaluate English–Arabic translations generated by Large Language Models (LLMs) using the COMET neural evaluation metric.

The example reproduces a complete translation evaluation workflow, including data preparation, COMET installation, execution, result interpretation, and comparison with expert human evaluation.

---

## Objectives

- Demonstrate automatic translation evaluation using COMET.
- Compare multiple LLM-generated translations.
- Illustrate reproducible evaluation workflows.
- Compare COMET scores with expert human assessment.

---

## Models Evaluated

- ChatGPT (GPT-5.5)
- Gemini 3.6 Flash
- Claude Sonnet 5 Thinking

---

## Workflow

1. Prepare the source text.
2. Create a professional reference translation.
3. Generate translations using multiple LLMs.
4. Run COMET evaluation.
5. Compare COMET scores.
6. Compare automatic evaluation with expert human evaluation.
