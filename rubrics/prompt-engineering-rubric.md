# Prompt Engineering Evaluation Rubric

## Purpose

This rubric is used to evaluate the quality of prompts designed for AI systems.

## Evaluation Criteria

- Prompt Clarity
- Specificity
- Context
- Structure
- Completeness
- Expected Output Definition
- Robustness
- Efficiency

## Evaluation Guidance

- Evaluate the prompt itself, not the AI-generated response.
- Consider whether the prompt provides sufficient context and instructions.
- Assess how effectively the prompt guides the AI toward the intended outcome.
- Support every score with explicit evidence from the prompt.
