# LLM Evaluation Rubric

## Purpose

This rubric is used to evaluate the quality of Large Language Model (LLM) responses.

## Evaluation Criteria

- Instruction Following
- Accuracy
- Clarity
- Completeness
- Helpfulness
- Fluency
- Tone
- Audience Appropriateness
- Cultural Appropriateness (when applicable)

## Evaluation Guidance

- Evaluate only criteria relevant to the task.
- Support every score with explicit evidence.
- Assess each criterion independently.
- Base conclusions on qualitative analysis rather than score averages.
