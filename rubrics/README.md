# Evaluation Rubrics

This directory contains reusable evaluation rubrics developed for the AI Evaluation Framework.

Evaluation rubrics provide structured criteria for assessing AI systems consistently and transparently across different tasks and domains.

Future rubrics may include:

- Large Language Model (LLM) Evaluation
- Translation Evaluation
- Prompt Engineering
- Medical AI
- AI Safety
- Reasoning
- Conversational AI
- Retrieval-Augmented Generation (RAG)

Rubrics will be added as they are developed, validated, and incorporated into the framework.
