# Translation Evaluation Rubric

## Purpose

This rubric is used to evaluate the quality of translated text.

## Evaluation Criteria

- Accuracy
- Faithfulness
- Fluency
- Terminology
- Consistency
- Cultural Adaptation
- Naturalness
- Style Preservation

## Evaluation Guidance

- Compare the translation with the source text.
- Evaluate only criteria relevant to the task.
- Support every score with explicit evidence.
- Distinguish translation accuracy from writing quality.
- Base conclusions on qualitative analysis rather than score averages.
