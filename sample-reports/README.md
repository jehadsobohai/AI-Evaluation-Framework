# Sample Reports

This directory is reserved for completed evaluation reports developed using the **AI Evaluation Framework**.

The framework provides reusable standards, methodologies, templates, and evaluation guidance. Complete real-world implementations of these standards are available in the companion repository:

## Companion Repository

👉 **LLM Evaluation Portfolio**

https://github.com/jehadsobohai/LLM-Evaluation-Portfolio

The portfolio demonstrates practical applications of the framework through fully documented evaluation case studies, including:

- Human-in-the-Loop (HITL) Evaluation
- COMET-Based Automatic Evaluation
- Modern Standard Arabic (MSA) Evaluation
- Egyptian Arabic Evaluation
- Prompt Engineering
- Comparative Model Analysis

Future releases of the AI Evaluation Framework will include generic sample reports that demonstrate framework usage independent of the portfolio.
