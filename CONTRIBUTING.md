# Contributing

Thank you for your interest in contributing to the AI Evaluation Framework.

We welcome contributions that improve the framework, including:

- Evaluation methodologies
- Domain-specific rubrics
- Documentation
- Sample evaluation reports
- Bug fixes and enhancements

## How to Contribute

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Submit a pull request with a clear description.

## Guidelines

- Follow the evidence-based evaluation methodology.
- Keep documentation clear and consistent.
- Preserve the framework's standardized report structure.
- Ensure changes are well documented.
