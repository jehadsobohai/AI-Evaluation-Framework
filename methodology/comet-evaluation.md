# COMET Evaluation Methodology

## Overview

COMET (Crosslingual Optimized Metric for Evaluation of Translation) is a neural evaluation metric designed to assess machine translation quality. Unlike traditional metrics such as BLEU, COMET uses pretrained multilingual language models to evaluate semantic similarity between a source sentence, a reference translation, and a candidate translation.

This methodology provides a reproducible workflow for evaluating translation quality generated by Large Language Models (LLMs).

---

## Evaluation Inputs

COMET requires three inputs:

| Input | Description |
|--------|-------------|
| Source | Original text |
| Reference | Human-produced translation |
| Candidate | Translation generated by an LLM |

---

## Workflow

1. Prepare the source text.
2. Produce a high-quality reference translation.
3. Generate candidate translations using one or more LLMs.
4. Format the evaluation data.
5. Execute COMET.
6. Compare scores.
7. Interpret the results.

## Score Interpretation

| COMET Score | Interpretation |
|--------------|----------------|
| 0.95–1.00 | Excellent |
| 0.90–0.95 | Very High Quality |
| 0.80–0.90 | Good |
| 0.70–0.80 | Acceptable |
| <0.70 | Needs Improvement |

*Interpret scores in the context of the evaluation task and reference translation.*

---

## Strengths

- Semantic evaluation rather than lexical matching
- Strong correlation with human judgments
- Supports multilingual translation evaluation
- Suitable for benchmarking LLM outputs
- Reproducible and automated

---

## Limitations

- Requires a high-quality reference translation
- Should not replace expert human evaluation
- Sensitive to reference quality
- May not capture stylistic preferences

---

## Best Practices

- Use professional reference translations.
- Evaluate multiple candidate models.
- Combine COMET with human evaluation.
- Report methodology for reproducibility.
