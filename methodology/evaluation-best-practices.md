## Purpose

This document provides recommended practices for conducting AI evaluations that are consistent, transparent, reproducible, and evidence-based.

These practices complement the **Evaluation Project Standard (EPS)** and the **Evaluation Methodology** by providing practical guidance for evaluators throughout the evaluation lifecycle.

---

## Scope

These recommendations apply to AI evaluation projects across multiple domains, including Large Language Models (LLMs), translation systems, prompt engineering, conversational AI, reasoning tasks, benchmark evaluations, and other AI applications.

---

## Planning

Before beginning an evaluation:

- Define clear evaluation objectives.
- Define the evaluation scope.
- Select appropriate evaluation criteria.
- Choose suitable evaluation methodologies.
- Prepare datasets, prompts, and evaluation assets.
- Document project metadata.

---

## Evaluation Execution

During evaluation:

- Apply the same evaluation procedure to all systems.
- Record prompts, model settings, and outputs.
- Preserve evaluation conditions.
- Document unexpected behaviors.
- Avoid modifying evaluation criteria during execution.

---

## Evidence Collection

Collect evidence that supports evaluation findings, including:

- Model responses
- Benchmark results
- Automatic evaluation metrics
- Human evaluator observations
- Error analyses
- Comparative results

Maintain sufficient documentation to support reproducibility.

---

## Analysis

When analyzing results:

- Compare systems using predefined criteria.
- Identify strengths and weaknesses.
- Distinguish objective observations from interpretations.
- Support conclusions with documented evidence.
- Report uncertainties where appropriate.

---

## Reporting

Evaluation reports should:

- Follow the **Evaluation Project Standard (EPS)**.
- Clearly describe the evaluation methodology.
- Document evidence supporting conclusions.
- Report limitations.
- Provide reproducible findings.

---

## Quality Assurance

Before publishing an evaluation:

- Verify project metadata.
- Verify evaluation criteria.
- Verify scoring consistency.
- Verify evidence supports conclusions.
- Review calculations and metrics.
- Confirm documentation is complete.
- Ensure compliance with the Evaluation Project Standard (EPS).

---

## Common Pitfalls

Avoid:

- Undefined evaluation objectives.
- Inconsistent evaluation criteria.
- Unsupported conclusions.
- Missing evidence.
- Poor documentation.
- Mixing objective observations with subjective opinions.
- Overinterpreting automatic evaluation metrics.
- Ignoring evaluation limitations.
